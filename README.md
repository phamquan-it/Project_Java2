## **Why?**

- 🚀 **Fast**: Designed with performance in mind to track scores efficiently.
- 💎 **Reliable**: Built with Java Swing for a responsive user interface and MySQL for secure, stable database management.
- 🌟 **Featured**: Supports a flexible database configuration and seamless integration with Java backend.
- ❤️ **Flexible**: Easily configurable properties file for dynamic database setup.
